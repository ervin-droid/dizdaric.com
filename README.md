# dizdaric.com

Personal website for Ervin Dizdaric.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

This is a static site and can be deployed directly to GitHub Pages, Vercel, Netlify or Cloudflare Pages.
